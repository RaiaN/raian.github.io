Solution overview for Sales and Solution Architects

What FilmAgent is

FilmAgent is an AI co-pilot for filmmakers. It covers screenwriting, asset generation, specialized AI skills and shot editing, and takes the existing project into account.

It works through natural language and precise editing.

Technically: built on Pi, a minimal harness framework. It uses ByteDance models (Seedance, Seedream, Seed) and specialized Skills written from best practice.
  • FilmAgent: ask in words; the agent does the work.
  • Studio: the same film, stage by stage.
  • Canvas: card-by-card control of one shot or edit.

The harness what sits between the director and the models

The harness is the agent loop that turns a request into finished work. For each request it plans the steps, calls one film tool per step, looks at what came back and decides the next step, until it can report. There is no fixed pipeline.

DirectorAsks in plain words, attaches references, names results as R1, T3 or @Name.
→
PlanThe planner model reads the request and the film, and chooses the next tool.
→
ActOne tool call: write, draw, shoot, edit, finish or assemble.
→
LookIt reads the result, including frames of every picture and take.
→
ReportWhat is done, what is not and why. The director picks.
Plan → Act → Look repeats until the request is done or a limit is reached
30 film toolsScreenplay, shot list, cast, variations, storyboard, previz, video, edit, finish, assemble.
SkillsThe agent's method, each model's prompt spec and each tool's prompts, as plain files.
Project contextThe cloud film is the memory: script, shots, plates and takes.
Run rulesLimits and checks in code that hold whatever the model decides.

What the harness holds

Tools30 film tools the agent can call. Each does one job and returns a named result: R for pictures, T for takes.
SkillsPrompts are written under each model's own spec (Seedance 2.5, Seedream, editing). Tool prompts and the agent's method are files a customer can read and change.
ContextOne cloud project per film. The agent reads only what a step needs, so a long project does not have to be reloaded into the model each time.
Assets by nameR1, T3 and @Name resolve to the right file and are numbered for the model. A prompt that cites an asset not in the render is refused in code.
Run rulesUp to 60 tool calls per request. A tool that refuses the same thing twice is closed for that request. A render's prompt must come from the prompt-writing step.
Director in the loopEvery step shows as it happens. The director can add a note while it works, stop it, and pick or reject results. Renders already started still land in the film.
ModelsPlanner: Seed 2.1 Turbo by default, Seed 2.0 Pro or Seed-Evolving selectable. Video: Seedance 2.5. Images: Seedream. Each slot is set by an environment variable.

Architecture Harness, Studio and Canvas

FilmAgent is a white-label solution: building blocks for the film industry that combine the Harness, Studio and Canvas spaces.

  • Harness (FilmAgent): one session drives the film through tools.
  • Cloud project: one film shared by all three.
  • Studio: Script, Cast & World, Scenes, Cut.
  • Canvas: Shot card, Previz, Edit card, Take Library, Final Cut.

Directing: control and masking

Control inputs reduce the error rate in complex shots, such as multi-character scenes or planned camera moves.

  • Directing: blocking, keyframes and reference video steer the take

Audio design

From an image and a prompt, the Audio agent on the Canvas generates sound with Seed Audio 1.0.

  • Ambient sounds
  • Voice-over
  • SFX

Seedance takes also come with their own sound.

Skills

Skills let FilmAgent solve the request and get the most out of each model without pre-defined workflows. Customers can create new skills and change existing ones.

  • Model skills: best-practice prompt writing for each model, bound to its model slots.
  • FilmAgent: the agent's own method.
  • Tool prompts: shared by FilmAgent, Studio and Canvas.

How to install API key and endpoints

git clone git@github.com:RaiaN/FilmAgent.git && cd FilmAgent
npm install && cp .env.example .env.local

Open .env.local and fill in:

# required
MODELARK_API_KEY, MODELARK_API_BASE_URL
MODELARK_MODEL_REASONER, MODELARK_MODEL_SEEDREAM, MODELARK_MODEL_SEEDREAM_PRO
MODELARK_ASSET_ACCESS_KEY, MODELARK_ASSET_SECRET_KEY
MODELARK_TOS_BUCKET, MODELARK_TOS_REGION
# add for Seedance 2.5 (30 s takes, MOV 10-bit)
MODELARK_MODEL_SEEDANCE_25=ep-...
MODELARK_MODEL_SEEDANCE_25_PREMIUM=ep-...
# optional
MODELARK_MODEL_SEEDANCE, _FAST, _MINI
BYTEPLUSVOICE_API_KEY, MODELARK_MODEL_SEED_AUDIO

Needs Node 18+ and git access to the repository.

Then start it:

NODE_USE_SYSTEM_CA=1 npm run dev

Open http://localhost:3000.

Projects and media are stored in the TOS bucket named in the file.
